# Nueve Mundos

Nueve Mundos es un proyecto de tienda online de indumentaria urbana desarrollado como proyecto final del curso de Desarrollo Web.

El sitio cuenta con diferentes secciones de productos como calzado, buzos, remeras, pantalones y perfumes, además de páginas de novedades, registro, carrito, política de cambios y cómo comprar.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS / Sass
- Bootstrap
- AOS (Animate On Scroll)
- Git
- GitHub

## Características

- Diseño responsive para dispositivos móviles, tablets y escritorio.
- Menú de navegación responsive realizado con Bootstrap.
- Uso de variables, nesting, mixins, extend, partials y @use en Sass.
- Animaciones y transiciones.
- Animaciones mediante la librería AOS.
- Optimización SEO mediante etiquetas meta y HTML semántico.
- Imágenes con atributos alt para mejorar la accesibilidad.
